\textbf{What is claimed is:}

1. A computing system, comprising:
\begin{itemize}[leftmargin=2.5em]
    \item[] a first chassis containing one or more processors;
    \item[] a second chassis, physically separate from the first chassis, containing one or more memory modules; and
    \item[] a high-bandwidth data fabric providing a communicative link between at least one processor in the first chassis and at least one memory module in the second chassis, the fabric having a data transfer rate sufficient to allow the processor to access the memory module as main memory.
\end{itemize}

2. The system of claim 1, further comprising a third chassis containing one or more storage devices, communicatively coupled to the data fabric.

3. The system of claim 1, further comprising a fourth chassis containing one or more accelerator cards, communicatively coupled to the data fabric.

4. The system of claim 1, wherein the data fabric has a data transfer rate exceeding 10 terabits per second.

5. The system of claim 1, wherein the first chassis and the second chassis are optimized with different cooling and power delivery systems.

6. The system of claim 1, wherein the high-bandwidth data fabric is a massively parallel optical data fabric.

7. The system of claim 6, wherein the fabric uses optical interconnects as described in U.S. Patent Application No. 19/559,705.
