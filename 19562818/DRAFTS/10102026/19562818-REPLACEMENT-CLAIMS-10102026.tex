\vspace{0.4cm}
\noindent What is claimed is:

\begin{enumerate}[label=\textbf{\arabic*.}, leftmargin=0.5in, itemsep=0.4cm]
    \item A computer data bus apparatus for transmitting data words between components, comprising:
    \begin{itemize}[leftmargin=0.3in, noitemsep]
        \item a plurality of parallel optical channels; and
        \item a controller configured to cause a single data word with a bit-width greater than 128 bits to be transmitted in a single cycle by encoding portions of the data word across the plurality of parallel optical channels.
    \end{itemize}

    \item The apparatus of claim 1, wherein the bit-width of the data word is 256 bits.

    \item The apparatus of claim 1, wherein the bit-width of the data word is 1024 bits.

    \item The apparatus of claim 1, wherein each parallel optical channel is a pixel within a two-dimensional array of pixels.

    \item The apparatus of claim 4, wherein a 256-bit data word is transmitted using 11 or fewer pixels.

    \item The apparatus of claim 4, wherein a 1024-bit data word is transmitted using 43 or fewer pixels.

    \item The apparatus of claim 1, wherein the bus is an implementation of the optical interface described in U.S. Patent Application No. 19/559,705.
\end{enumerate}
